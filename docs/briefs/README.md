# Decision briefs

Every decision Gitesh makes gets a brief in this format (decision #5, 8 Oct 2026), in whichever chat it comes up.
Applying an existing rule (a retime under the connection rule, logging an order, marking a to-do) is not a decision
and gets no brief.

Save each brief here as `<date>-<topic>.md` (for example `2026-10-08-virgin-order.md`). Once decided, add the outcome
at the bottom, and update the operating manual in the same turn if the decision makes or changes a rule.

## Format
Lead with the answer; detail goes below, so it reads quickly on a phone.

```
# <Decision, in a few words> — <date>

**Decision:** <what has to be decided, one line>
**Recommendation:** <the option, and why in one line>

| Option | Growth | Profit a week | Cash at the lowest point | Opportunity cost | Risk | Easy to undo? |
|---|---|---|---|---|---|---|
| A ... | new markets, departures, seats | from route profit or the forecast | from the cash forecast | what it rules out | | |
| B ... | | | | | | |

## Background
What the data shows, each figure with its source (capture date, planner board or table). Competition by market.

## Scenarios and the risk of waiting
What happens under each option if things go well or badly, and what waiting costs.

## What would change the recommendation

## Outcome
<Gitesh's decision and the date; rule changes made in the manual>
```
