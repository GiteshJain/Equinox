## Lessons
- **Safari's Page Source holds only a JavaScript site's shell:** the sign-in form wasn't in it. Read the drawn page in
  the built-in browser (signed out, public pages only) or ask for a screenshot. Gitesh's screenshot of the world list
  showed the paid "Play for 4 credits/day" buttons: a page that can spend money gets an exact-match rule and decoy tests.
- **A helper's new read must pass new fields through:** the Systems read listed its fields one by one, and the new
  `unattended` part was dropped until the rehearsal's planner step caught it.
- **`xmin = pg_current_xact_id()` misses writes made in a subtransaction** (`capture_store()` parses in one): count
  writes by ctid/xmin before and after.
- **A delete inside a function body still gets the chat's apply cancelled** (#147): go straight to the SQL editor link
  after one retry.
- **Secrets pasted by hand go wrong:** the first unattended run failed on the key (quotes or a stray character); the
  job's own check said so in one line and nothing touched the game. Ask Gitesh to re-paste rather than guess.
- From before, still true: test against a page saved from the game (or read in a browser), never one built from a
  description; when a page posts a plain form, send the form; a rehearsal test reading the copy's real data goes stale.
