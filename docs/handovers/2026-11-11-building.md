## Lessons
*The first twelve are from the Main chat's build workers, 11 Nov evening (the Main-chat trial).*
- **A mock-up made from an artifact type can't be read as a page or for its pictures:** `read_artifact` and `read_asset`
  refuse it. `list_files` then `read_file` with `path` give its text files; `list_assets` gives each picture's size and
  sha256 only. No chat or worker can get the picture itself (the glass look's three backdrops, to-do 225).
- **Check what a screen really does before naming it in a brief:** Reference went into the glass look's decision 4 as a
  one-airline screen; it shows all six.
- **Count before quoting a count:** the stylesheet has about 413 typed-in colours and the code 113 more (not 324), with
  39 screen files and 51 tables, measured at bc7612e.
- **`grep` in the worker's sandbox is ugrep and ignores `--include`:** search by directory.
- **A rehearsal's parts can be timed from its log:** `database/rehearse.sh` prints timestamped `==` headings. Job ids
  from `gh api repos/GiteshJain/Equinox/actions/runs/<id>/jobs`, then `.../actions/jobs/<job id>/logs`. Compare runs by
  part, not by total: GitHub's machines vary close to 2x (20 to 31 minutes for the same work on 11 Nov).
- **GitHub from a chat is REST only:** `gh api repos/GiteshJain/Equinox/...` works; `gh pr list`, `gh run view` and
  anything else on GraphQL is refused. Open a pull request with `gh api -X POST .../pulls`.
- **A helper every chart passes through must accept what the old code tolerated** (12 Nov, pull request 153): the
  glass look's `paint()` called `toUpperCase` on a mark with no colour, which Competition's donut gives a rival in a
  market the airline doesn't fly. Undefined used to draw quietly; it crashed the whole planner in the rehearsal.
- **Since the stored figures (#150, #151), a rehearsal check that compares a screen with a database call makes the call
  at the stored set's moment, not now():** use `set_moment_sql()` in `tests/planner_next_test.py`. Anything with a
  7-day window or a "safe from" date drifts with the clock (Competition's threats: 5 shown against 4, 12 Nov).
- **`tests/look_colours_test.py` counts "#" plus three hex digits anywhere in planner code, comments included:** write
  "pull request 153", not the number with a hash.
- **The glass look's steps:** the contrast check decides a step's colours (the mock-up's own pill colours failed it), so
  run it as soon as glass values change; a glass rule needs at least the old rule's specificity
  (`.wcard.file .wkind`); judge the look in a window-sized screenshot, since a full-page one shows the fixed backdrop
  only for the first screen height; a script that resolves every named colour to its light value on main and on the
  branch proves the light look is unchanged.
- **A step that fails in "Install the test browser" with "Temporary failure resolving security.ubuntu.com" is GitHub's
  network, not the change** (11 Nov, 14:17 to about 21:20 UTC, every run). Re-run the failed jobs once it clears.
- **The screen check can set the browser up first:** `Planner.open(init=...)` runs a script before the page loads.
- **A big migration can't be retyped through the chat:** fetch the merged raw file inside the database
  (`net.http_get` on raw.githubusercontent.com), check its md5 against the repository's, run it in a `do` block, then
  insert the `schema_migrations` row.
- **A function's `set statement_timeout` doesn't hold inside a `pg_cron` job** (the server's 2 minutes does): keep each
  minute's work short and resumable, as the route pages are.
- **A shadowing constant in a long test file cost a 45-minute rehearsal** (a second `READY` dict): grep a test file for
  a name before adding it.
- **A test that edits the database behind the planner's back must store a new set** (`store_figures()` in
  `tests/planner_next_test.py`), or the screen shows the old answer.
- From before, still true: test against a page saved from the game, never one built from a description; a delete inside
  a function body gets the chat's apply cancelled, so go to the SQL editor after one retry.
