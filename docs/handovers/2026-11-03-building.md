## Lessons
- **Supabase cuts calls through the API off at 60 s, whatever a function's `statement_timeout` says.** A call that
  needs longer is split (as #131), not given a bigger limit. Noted in the map's *When something breaks*.
- **A new function with its own limit** must be added to the list in `database/tests/figures_timeout_test.sql`.
- **A new public function changes the planner's generated types:** take `app/planner/src/db/types.ts` from the
  rehearsal's `planner-types` artifact.
- **`.back` in the planner's styles hides anything with that class** (it's the back button's). Never name a chart part `back`.
- **Big `create or replace` functions** (#132's was 49 KB) went as a file for the SQL editor, as before; check live
  afterwards by hashing `pg_get_functiondef()` without whitespace against the tested file.
- The rehearsal's Systems board shows the copy's database size (420 MB on 2 Nov), not live's (220 MB).
