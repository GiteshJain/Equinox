## Lessons
- **Test the capture against a page saved from the game, never one built from a description.** The salary step passed
  every test on a made-up page and failed on the real one for a reason the made-up page couldn't show (one name for every
  box). Ask Gitesh for the page (Safari → File → Save As → Page Source) before building on a game page.
- **When a page posts a plain form, send the form** (as the fares and salaries do) rather than typing and clicking.
- **A rehearsal test that reads the copy's real data goes stale** when the data moves on (a setting switched on, rows
  cleaned up, prices changed): fix the test to what still holds, and check first that it hasn't found a real bug.
- **Don't guess twice at a game behaviour:** after one wrong guess (1.13's retries), get the evidence (a screenshot, the
  page, Gitesh pressing the button once) before the next change.
- From 5 Nov, still true: `delete from` in SQL makes the chat's apply come back "cancelled" (keep it out of migrations);
  big migrations are applied by a helper that hashes each function against the file; helpers clone their own copies.
