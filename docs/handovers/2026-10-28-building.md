## Lessons for helpers (add to the earlier notes)
- `gh pr create` is blocked (GraphQL): open pull requests with `gh api repos/GiteshJain/Equinox/pulls -X POST ...`.
- In a database test, never read a big function's result inside a query that refers to it per row (`from (select
  f() as d) dd ... dd.d` in aggregates): the planner calls it again per row. Put it in a variable first. (#116's
  rehearsal ran past 45 minutes that way.)
- Two pull requests adding settings the same night both touch `database/tests/rules_input_test.sql`'s list of new
  settings; the second must add its own after rebasing.
- Saved game pages from Safari: File → Save As → **Web Archive** (the tool's results don't survive Page Source). The
  Userscripts app writes the capture key into the page, so scrub fixtures to the tool's own part.
