## How we work now (all in the manual §1)
- **No polling.** Helpers write the code, run the local checks, open the pull request and stop. The Building chat
  waits on the checks with one background shell loop (`gh api …/check-runs` every 60 s; it costs no Claude usage) and
  sends a red check back to the helper with the log.
- **Merging is Gitesh's "merge"** (the new-look exception ended with step 4).
- **Applying a migration after "merge":** apply it from the chat, then compare each function against
  `database/current/functions.sql` (md5 of the body with whitespace removed) and set the migration record's version.
  Apply the file's text exactly, comments included: comments inside function bodies are part of the definition, and a
  re-typed copy without them no longer matches. For a very large file (60 KB on #77), give Gitesh the raw GitHub link
  to run in Supabase's SQL editor instead, then record and check it. Removals (dropping a rule, column or table) are
  always his to run.

## Lessons from today
- **A pull request in conflict with main runs no checks** (GitHub starts no `pull_request` workflows while
  `mergeable_state` is `dirty`). If checks don't appear, merge main into the branch first.
- **Docs edited by hand break the rehearsal:** the table guide (`docs/data.md`) is generated from the database; a
  hand edit without a migration fails every pull request's rehearsal (fixed on main in `01e467f`; the description was
  then made properly in #78). Other chats must change descriptions through a migration.
- **The rehearsal tests on last night's backup,** so a new kind of data in the backup can break an old test (the
  history snapshot test on 22 Oct: two captures either side of midnight UTC; fixed in the test in #76).
- **Helpers share no folder:** give each its own clone (`/home/claude/<name>-build`); `/home/claude/equinox` is the
  Building chat's.
- **Facts first:** today's slip was saying Lucknow was contested; it wasn't in Gander (Inter Connect is the Ellinikon
  world). Check the world scan before saying anything about rivals.
